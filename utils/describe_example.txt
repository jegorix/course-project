Основные классы транспортных средств:
Класс Transport
Данный класс является базовым для всей иерархии транспортных
средств в системе. Предоставляет общий функционал для работы с основными
атрибутами транспорта.

std::string brand – поле для хранения марки;
std::string model – поле для хранения модели;
int year_of_manufacture – поле для хранения года выпуска.
Методы:

model_, int year) – конструктор с параметрами;
Transport(const Transport& other) – конструктор копирования;
~Transport() – виртуальный деструктор;
std::string getBrand() const – метод получения марки;
std::string getModel() const – метод получения модели;
int getYearOfManufacture() const – метод получения года выпуска;
void setBrand(const std::string& b) – метод изменения марки;
void setModel(const std::string& m) – метод изменения модели;
void setYearOfManufacture(int y) – метод изменения года выпуска;
friend std::ostream& operator<<(std::ostream& os, const
Transport& t) – перегрузка оператора вывода в поток;
friend std::istream& operator>>(std::istream& is, Transport&
t) – перегрузка оператора ввода из потока.
