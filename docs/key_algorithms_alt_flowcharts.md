## Блок-схемы альтернативных ключевых алгоритмов

Ниже приведены блок-схемы по шагам для двух алгоритмов класса `DataManager`: формирования рейтинга отделов по эффективности затрат (`buildDepartmentsEfficiencyRating`) и вычисления средней заработной платы по отделу (`calculateAverageSalaryForDepartment`). Схемы оформлены в текстовом виде, чтобы их можно было легко перерисовать в графическом редакторе по образцу из курсовой.

---

#### Краткое текстовое описание шагов и фрагменты кода

1. **Шаг 2. Инициализировать пустой вектор rating (std::vector<pair<int,double>>)**  
   - Код:
     ```cpp
     std::vector<std::pair<int, double>> rating;
     ```

2. **Шаг 3. Цикл по всем отделам в departments (i от 0 до departments.size() - 1)**  
   - Код:
     ```cpp
     for (const auto& dept : departments) {
         int departmentId = dept.getDepartmentId();
         // ...
     }
     ```

3. **Шаг 4. Инициализировать totalSalary = 0.0 и count = 0 для текущего отдела**  
   - Код:
     ```cpp
     double totalSalary = 0.0;
     std::size_t count  = 0;
     ```

4. **Шаг 5. Вложенный цикл по всем сотрудникам в контейнере employees (i от 0 до employees.size() - 1)**  
   - Код:
     ```cpp
     for (const auto& record : employees) {
         if (!record.employee) {
             continue;
         }
         if (record.employee->getDepartmentId() != departmentId) {
             continue;
         }
         // ...
     }
     ```

5. **Шаг 5 (продолжение). Добавить salary сотрудника к totalSalary и увеличить count = count + 1**  
   - Код:
     ```cpp
     totalSalary += record.employee->getSalary();
     ++count;
     ```

6. **Шаг 6. Проверка totalSalary и count и вычисление коэффициента efficiency**  
   - Код:
     ```cpp
     double efficiency = 0.0;
     if (count > 0 && totalSalary > 0.0) {
         efficiency = static_cast<double>(count) / totalSalary;
     }
     ```

7. **Шаг 7. Добавить пару (departmentId, efficiency) в вектор rating**  
   - Код:
     ```cpp
     rating.emplace_back(departmentId, efficiency);
     ```

8. **Шаг 8. Отсортировать rating по убыванию efficiency (std::sort с компаратором)**  
   - Код:
     ```cpp
     std::sort(
         rating.begin(),
         rating.end(),
         [](const auto& lhs, const auto& rhs) {
             return lhs.second > rhs.second;
         }
     );
     ```

9. **Шаг 9. Вернуть вектор rating как результат функции buildDepartmentsEfficiencyRating**  
   - Код:
     ```cpp
     return rating;
```

#### Краткое текстовое описание шагов и фрагменты кода

1. **Шаг 2. Найти отдел по departmentId (findDepartment). Если не найден — вернуть 0.0 и завершить функцию**  
   - Код:
     ```cpp
     const Department* department = findDepartment(departmentId);
     if (!department) {
         return 0.0;
     }
     ```

2. **Шаг 3. Инициализировать sumSalary = 0 и count = 0**  
   - Код:
     ```cpp
     double sumSalary = 0.0;
     std::size_t count = 0;
     ```

3. **Шаг 4. Цикл по всем сотрудникам (i от 0 до employees.size() - 1)**  
   - Код:
     ```cpp
     for (const auto& record : employees) {
         if (!record.employee) {
             continue;
         }
         if (record.employee->getDepartmentId() != departmentId) {
             continue;
         }
         // ...
     }
     ```

4. **Шаг 4 (продолжение). Получить оклад salary, добавить к sumSalary и увеличить count = count + 1**  
   - Код:
     ```cpp
     double salary = record.employee->getSalary();
     sumSalary += salary;
     ++count;
     ```

5. **Шаг 5. Проверить значение count; если count == 0, вернуть 0.0 (нет данных)**  
   - Код:
     ```cpp
     if (count == 0) {
         return 0.0;
     }
     ```

6. **Шаг 6–7. Вычислить averageSalary = sumSalary / count и вернуть его как результат функции**  
   - Код:
     ```cpp
     return sumSalary / static_cast<double>(count);
```
