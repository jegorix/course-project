## Блок-схемы ключевых алгоритмов (по шагам)

Ниже приведены текстовые схемы для двух алгоритмов, оформленные по шагам так, как на примере из курсовой. Каждый блок соответствует одному шагу алгоритма, условия выделены ромбами с ветвями «да/нет», циклы показаны обратными стрелками.

---

### 2. Алгоритм отмены последнего действия (DataManager::undoLastAction)

```text
     ┌───────────────┐
     │    НАЧАЛО     │
     └──────┬────────┘
            │
 ┌──────────▼─────────────────────────────┐
 │ Шаг 2. Проверка: есть ли команды       │
 │ в стеке undoStack (canUndo)           │
 └──────────┬─────────────────────────────┘
            │
      ┌─────▼───────┐
      │ Стек пуст?  │  (ромб)
      └─────┬───┬───┘
           да   нет
           │     │
           │     │
 ┌─────────▼┐    │
 │ Вернуть  │    │
 │ false    │    │
 │ (отмена  │    │
 │  невозможна)  │
 └─────────┬┘    │
           │     │
           │     │
           │     ▼
           │  ┌───────────────┐
           │  │ Шаг 3. Взять  │
           │  │ верхний       │
           │  │ UndoCommand   │
           │  │ и удалить его │
           │  │ из undoStack  │
           │  └─────┬─────────┘
           │        │
           │  ┌─────▼─────────────────────┐
           │  │ Шаг 4. Установить        │
           │  │ undoInProgress = true    │
           │  └─────┬─────────────────────┘
           │        │
           │  ┌─────▼─────────────────────┐
           │  │ Шаг 5. Вызвать            │
           │  │ команду undo()           │
           │  │ (восстановить данные)    │
           │  └─────┬─────────────────────┘
           │        │
           │  ┌─────▼─────────────────────┐
           │  │ Шаг 6. Установить         │
           │  │ undoInProgress = false    │
           │  └─────┬─────────────────────┘
           │        │
           │  ┌─────▼─────────────────────┐
           │  │ Шаг 7. Сохранить текстовое│
           │  │ описание отменённого      │
           │  │ действия (description)    │
           │  └─────┬─────────────────────┘
           │        │
           │  ┌─────▼─────────────────────┐
           │  │ Шаг 8. Вернуть true       │
           │  └─────┬─────────────────────┘
           │        │
           └────────┘
            │
     ┌──────▼────────┐
     │     КОНЕЦ     │
     └───────────────┘
```
