================================================================================
ПОЛНЫЙ ФУНКЦИОНАЛ QT ИНТЕРФЕЙСА С ВАЛИДАЦИЕЙ
================================================================================

1. УПРАВЛЕНИЕ СОТРУДНИКАМИ
================================================================================

1.1. Добавление сотрудника
------------------------------------------------
- Выбор типа: Работник или Руководитель
- Ввод имени и фамилии (валидация: не могут быть пустыми)
- Выбор отдела из списка (валидация: должен быть выбран отдел)
- Ввод зарплаты (валидация: > 0)
- Для работника:
  * Выбор должности (валидация: должна быть выбрана)
  * Ввод премии
- Для руководителя:
  * Выбор подчиненных из списка работников
  * Добавление/удаление подчиненных
- Выбор даты и времени найма
- Автоматическое сохранение после добавления

1.2. Редактирование сотрудника
------------------------------------------------
- Редактирование всех полей сотрудника
- Для работника: редактирование должности и премии
- Для руководителя: управление списком подчиненных
  * Добавление подчиненных из списка доступных работников
  * Удаление выбранных подчиненных
- Редактирование даты найма
- Валидация всех полей при сохранении

1.3. Удаление сотрудника
------------------------------------------------
- Выбор сотрудника из таблицы
- Подтверждение удаления
- Автоматическое удаление из отдела
- Отмена действия через Undo

2. УПРАВЛЕНИЕ ОТДЕЛАМИ
================================================================================

2.1. Добавление отдела
------------------------------------------------
- Ввод названия (валидация: не может быть пустым)
- Выбор руководителя из списка менеджеров (опционально)
- Автоматическое сохранение

2.2. Редактирование отдела
------------------------------------------------
- Изменение названия (валидация: не может быть пустым)
- Изменение руководителя
- Отображение количества сотрудников в отделе

2.3. Удаление отдела
------------------------------------------------
- Проверка наличия сотрудников (нельзя удалить отдел с сотрудниками)
- Подтверждение удаления
- Отмена действия через Undo

3. УПРАВЛЕНИЕ ДОЛЖНОСТЯМИ
================================================================================

3.1. Добавление должности
------------------------------------------------
- Ввод названия (валидация: не может быть пустым)
- Ввод часов в неделю (валидация: 1-168)
- Автоматическое сохранение

3.2. Редактирование должности
------------------------------------------------
- Изменение названия (валидация: не может быть пустым)
- Изменение часов в неделю (валидация: 1-168)

3.3. Удаление должности
------------------------------------------------
- Проверка использования (нельзя удалить используемую должность)
- Подтверждение удаления
- Отмена действия через Undo

4. ПОИСК И СОРТИРОВКА
================================================================================

4.1. Поиск сотрудников
------------------------------------------------
- По отделу (выбор из списка)
- По диапазону зарплаты (мин/макс)
- По фрагменту имени (поиск подстроки)
- Комбинирование критериев
- Отображение результатов в таблице с названиями отделов

4.2. Сортировка сотрудников
------------------------------------------------
- По ID
- По отделу
- По зарплате
- По фамилии
- По дате найма
- Направление: по возрастанию/убыванию
- Отображение результатов в таблице

5. АНАЛИТИКА (ДВА ОСНОВНЫХ АЛГОРИТМА)
================================================================================

5.1. Средняя зарплата по отделу
------------------------------------------------
- Выбор отдела из списка
- Автоматический расчет средней зарплаты
- Отображение результата с форматированием

5.2. Рейтинг отделов по эффективности
------------------------------------------------
- Автоматический расчет эффективности для всех отделов
- Сортировка по убыванию эффективности
- Отображение в виде таблицы с названиями отделов
- Форматированный вывод с номерами мест

6. ОТМЕНА ДЕЙСТВИЙ (UNDO)
================================================================================

6.1. Отмена последнего действия
------------------------------------------------
- Доступно через меню "Правка -> Отменить"
- Работает для всех операций:
  * Добавление/удаление/редактирование сотрудников
  * Добавление/удаление/редактирование отделов
  * Добавление/удаление/редактирование должностей
- Автоматическое обновление интерфейса после отмены
- Сохранение данных после отмены

7. ВАЛИДАЦИЯ ДАННЫХ
================================================================================

7.1. Проверки при добавлении/редактировании
------------------------------------------------
- Имя и фамилия: не могут быть пустыми
- Зарплата: должна быть > 0
- Название отдела: не может быть пустым
- Название должности: не может быть пустым
- Часы работы: от 1 до 168
- Должность: должна быть выбрана для работника
- Отдел: должен быть выбран

7.2. Проверки при удалении
------------------------------------------------
- Отдел: нельзя удалить, если в нем есть сотрудники
- Должность: нельзя удалить, если она используется
- Подтверждение перед удалением

7.3. Обработка ошибок
------------------------------------------------
- Все операции обернуты в try-catch
- Понятные сообщения об ошибках пользователю
- Предотвращение потери данных при ошибках

8. ОТОБРАЖЕНИЕ ДАННЫХ
================================================================================

8.1. Таблицы
------------------------------------------------
- Сотрудники: ID, ФИО, Отдел (название), Зарплата, Тип
- Отделы: ID, Название, Руководитель (имя), Количество сотрудников
- Должности: ID, Название, Часов в неделю
- Автоматическое изменение размера колонок
- Выбор строк для редактирования/удаления

8.2. Выпадающие списки
------------------------------------------------
- Отделы: показывают названия вместо ID
- Должности: показывают названия вместо ID
- Руководители: показывают ФИО вместо ID
- Работники: показывают ФИО для выбора подчиненных

9. АВТОМАТИЧЕСКОЕ СОХРАНЕНИЕ
================================================================================

- Сохранение после каждой операции изменения данных
- Ручное сохранение через меню "Файл -> Сохранить"
- Сообщения об успешном сохранении

10. ОБНОВЛЕНИЕ ИНТЕРФЕЙСА
================================================================================

- Автоматическое обновление всех таблиц после изменений
- Обновление после добавления/редактирования/удаления
- Обновление после отмены действий
- Синхронизация данных между таблицами
