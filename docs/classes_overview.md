# Описание классов проекта

Ниже — обзор ключевых классов и структур: их роль, важные поля и методы, а также то, как они взаимодействуют в системе управления персоналом.

## Базовая модель сотрудников
- **Person** (`include/Person.h`): базовый абстрактный тип человека, хранит имя/фамилию, умеет собирать ФИО и объявляет виртуальный `displayInfo()`.
- **Employee** (`include/Employee.h` + `src/Employee.cpp`): наследует `Person`, добавляет идентификатор сотрудника, отдел, оклад. Реализует вывод и базовый расчёт дохода (равен окладу).
- **Worker** (`include/Worker.h` + `src/Worker.cpp`): сотрудник-исполнитель; добавляет должность (`positionId`) и премию, пересчитывает доход как оклад + премия.
- **Manager** (`include/Manager.h` + `src/Manager.cpp`): руководитель; хранит список подчинённых, операции добавления/удаления, проверку наличия, вывод информации. Доход сейчас равен окладу.

## Организация и должности
- **Department** (`include/Department.h` + `src/Department.cpp`): отдел с id, названием, id руководителя и списком сотрудников. Методы добавления/удаления/проверки сотрудника, очистки списка и вывод информации.
- **Position** (`include/Position.h` + `src/Position.cpp`): должность с id, названием и недельной нормой часов. Методы доступа/изменения и вывод информации.
- **HireDate** (`include/HireDate.h` + `src/HireDate.cpp`): дата и время найма сотрудника; предоставляет форматированные строки даты/времени и вывод.

## Инфраструктура хранения
- **RecordCollection\<T\>** (`include/RecordCollection.h`): обёртка над `std::vector` с собственным random access итератором, методами `findIf`, `removeIf`, `insertionSort`, `forEach`, доступом к данным и размеру. Используется как контейнер для сотрудников, отделов и должностей.
- **Исключения** (`include/Exceptions.h`): иерархия `AppException` и специализированные типы (`ValidationException`, `EntityNotFoundException`, `OperationNotAllowedException`, `FileAccessException`, `DataFormatException`, `CollectionBoundsException`) для явной сигнализации бизнес- и IO-ошибок.

## Менеджер данных и файловый слой
- **DataManager** (`include/DataManager.h` + `src/DataManager.cpp`): центральное хранилище и точка бизнес-операций. Держит коллекции сотрудников (`EmployeeRecord` — пара `shared_ptr<Employee>` + `HireDate`), отделов и должностей, а также индексные таблицы для быстрого поиска по id. Отвечает за:
  - загрузку/сохранение всех данных через `FileManager`;
  - валидацию входных данных (непустые поля, положительная зарплата, корректные даты, валидные часы);
  - CRUD по сотрудникам, отделам и должностям с проверками связей (наличие отдела/должности, тип подчинённого и т.д.);
  - учёт принадлежности сотрудников к отделам (добавление/удаление id в списках отдела);
  - стек `undo` (хранит лямбда-команды и описания, позволяет откатить последнее действие и показывает описание последнего отката);
  - генерацию новых id и сброс данных (с сохранением возможности отката).
- **FileManager** (`include/FileManager.h` + `src/FileManager.cpp`): слой ввода/вывода. Читает и пишет файлы `positions.txt`, `departments.txt`, `employees.txt`, `hires.txt`; парсит/валидирует строки, создаёт сущности, поддерживает `next*Id` при загрузке, сохраняет сущности в текстовом формате, создаёт директории при необходимости. Работает через публичные поля/друзья `DataManager`.

## Алгоритмы и аналитика
- **Algorithm** (`include/Algorithm.h` + `src/Algorithm.cpp`): инкапсулирует поиск/сортировку/аналитику:
  - фильтр сотрудников по отделу, зарплате, должности, фрагменту имени;
  - сортировка сотрудников по id, отделу, зарплате, фамилии, дате найма (с опцией обратного порядка);
  - расчёт средней зарплаты по отделу;
  - рейтинг отделов по эффективности (кол-во сотрудников / суммарный оклад);
  - статистика ФОТ по отделам (оклад, премии, итог, доля премий), сортировка по убыванию ФОТ;
  - вспомогательные методы поиска записей/отделов/должностей в `DataManager` через его индексы.

## UI-слой
- **MainWindow** (`include/MainWindow.h` + `src/MainWindow.cpp`): главное окно Qt, соединяет UI с `DataManager` и `Algorithm`. Отвечает за:
  - создание и настройку вкладок/таблиц, кнопок, диалогов ввода;
  - операции добавления/редактирования/удаления/сброса для сотрудников, отделов, должностей с показом сообщений об ошибках;
  - поиск/сортировку и вывод результатов в таблицы;
  - аналитические отображения (средняя зарплата отдела, рейтинг эффективности, топ по ФОТ);
  - вызов `undo` последнего действия.

## Вспомогательные структуры
- **EmployeeRecord** (`include/DataManager.h`): связка `shared_ptr<Employee>` и `HireDate`, единица хранения в коллекции сотрудников.
- **EmployeeSearchFilter** (`include/DataManager.h`): набор флагов/значений для фильтрации сотрудников (отдел, должность, зарплатный диапазон, фрагмент имени).
- **EmployeeSortKey** (`include/DataManager.h`): перечисление ключей сортировки сотрудников.
