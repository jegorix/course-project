ПОЛНОЕ ОПИСАНИЕ ПРОЕКТА "СИСТЕМА КАДРОВОГО УЧЕТА НА МАЛОМ ПРЕДПРИЯТИИ"
================================================================================

1. ОБЩАЯ АРХИТЕКТУРА ПРОЕКТА
================================================================================

Проект реализован на C++17 с использованием Qt6 для графического интерфейса.
Приложение представляет собой систему управления кадрами с возможностью
учета сотрудников, отделов и должностей.

Основные компоненты:
- Иерархия классов для представления сотрудников (Person -> Employee -> Worker/Manager)
- Классы для представления отделов и должностей
- Менеджер данных (DataManager) для управления всеми операциями
- Пользовательский интерфейс на Qt6


2. ИЕРАРХИЯ КЛАССОВ (3 УРОВНЯ НАСЛЕДОВАНИЯ)
================================================================================

Уровень 1: Person (базовый абстрактный класс)
- Атрибуты: firstName, lastName
- Методы: getFirstName(), getLastName(), getFullName()
- Виртуальный метод: displayInfo() = 0

Уровень 2: Employee (наследует от Person)
- Атрибуты: employeeId, departmentId, salary
- Методы: getEmployeeId(), getDepartmentId(), getSalary()
- Виртуальные методы: displayInfo(), calculateTotalIncome()

Уровень 3: Worker и Manager (наследуют от Employee)
- Worker: positionId, bonus
- Manager: subordinates (вектор ID подчиненных)


3. КОНТЕЙНЕРЫ
================================================================================

3.1. Собственный контейнер RecordCollection<T>
------------------------------------------------
Шаблонный класс-обертка над std::vector<T> с дополнительной функциональностью:
- Методы: add(), at(), size(), empty(), clear()
- Поиск: findIf() - поиск по предикату
- Удаление: removeIf() - удаление по условию
- Сортировка: insertionSort() - сортировка вставками
- Итератор: собственный класс Iterator с проверкой границ

Использование:
- RecordCollection<EmployeeRecord> employees - хранит сотрудников
- RecordCollection<Department> departments - хранит отделы
- RecordCollection<Position> positions - хранит должности

3.2. Стандартные контейнеры STL
------------------------------------------------
- std::vector<int> - в Department (список сотрудников), Manager (подчиненные)
- std::vector<UndoCommand> - стек отмены действий в DataManager
- std::unordered_map<int, std::size_t> - индексы для быстрого поиска:
  * employeeIndex - индекс сотрудников по ID
  * departmentIndex - индекс отделов по ID
  * positionIndex - индекс должностей по ID
- std::vector<std::pair<int, double>> - результат рейтинга отделов


4. ИСКЛЮЧЕНИЯ (EXCEPTION HANDLING)
================================================================================

4.1. Используемые исключения
------------------------------------------------
- std::runtime_error - для ошибок выполнения (загрузка/сохранение файлов)
- std::out_of_range - в итераторе RecordCollection при выходе за границы
- std::exception - базовый класс для всех исключений

4.2. Места обработки исключений
------------------------------------------------
1. DataManager::loadAll() - оборачивает загрузку данных в try-catch
2. DataManager::saveAll() - оборачивает сохранение данных в try-catch
3. DataManager::addWorker/addManager - проверка существования отдела/должности
4. RecordCollection::Iterator - проверка границ при доступе к элементам
5. MainWindow (Qt интерфейс) - обработка всех операций с данными

4.3. Примеры обработки
------------------------------------------------
try {
    manager->loadAll();
} catch (const std::exception& e) {
    QMessageBox::critical(this, "Ошибка", QString("Ошибка: %1").arg(e.what()));
}


5. ОСНОВНЫЕ АЛГОРИТМЫ
================================================================================

5.1. Алгоритм 1: Рейтинг отделов по эффективности затрат
------------------------------------------------
Метод: DataManager::buildDepartmentsEfficiencyRating()

Шаги:
1. Создать пустой вектор rating для результатов
2. Для каждого отдела:
   a. Получить ID отдела
   b. Пройти по всем сотрудникам и найти принадлежащих отделу
   c. Подсчитать общую сумму зарплат (totalSalary) и количество (count)
   d. Вычислить эффективность: efficiency = count / totalSalary
   e. Добавить пару (departmentId, efficiency) в rating
3. Отсортировать rating по убыванию efficiency
4. Вернуть отсортированный вектор

Сложность: O(n*m + k*log(k)), где n - количество отделов, m - сотрудников, k - отделов

5.2. Алгоритм 2: Вычисление средней зарплаты по отделу
------------------------------------------------
Метод: DataManager::calculateAverageSalaryForDepartment(int departmentId)

Шаги:
1. Проверить существование отдела
2. Инициализировать sumSalary = 0.0 и count = 0
3. Пройти по всем сотрудникам:
   a. Пропустить, если employee == nullptr
   b. Пропустить, если departmentId не совпадает
   c. Добавить salary к sumSalary, увеличить count
4. Если count == 0, вернуть 0.0
5. Вернуть sumSalary / count

Сложность: O(m), где m - количество сотрудников


6. МЕХАНИЗМ ОТМЕНЫ ДЕЙСТВИЙ (UNDO)
================================================================================

6.1. Структура UndoCommand
------------------------------------------------
struct UndoCommand {
    std::function<void()> undo;  // Лямбда-функция для отката
    std::string description;     // Описание действия
};

6.2. Реализация
------------------------------------------------
- undoStack - вектор UndoCommand для хранения команд
- undoInProgress - флаг, предотвращающий создание новых команд при откате
- pushUndo() - добавление команды в стек
- undoLastAction() - выполнение последней команды отката

6.3. Пример использования
------------------------------------------------
При добавлении сотрудника:
pushUndo([this, id]() {
    removeEmployee(id);
}, "Добавление работника");


7. РАБОТА С ФАЙЛАМИ
================================================================================

7.1. Формат файлов
------------------------------------------------
employees.txt: ID;TYPE;FirstName;LastName;DepartmentId;Salary;PositionId;Bonus
departments.txt: ID;Name;ManagerId;EmployeeIds (через запятую)
positions.txt: ID;Name;HoursPerWeek
hires.txt: EmployeeId;Day;Month;Year;Hour;Minute

7.2. Методы загрузки/сохранения
------------------------------------------------
- loadAll() - загружает все данные из файлов
- saveAll() - сохраняет все данные в файлы
- loadEmployees(), loadDepartments(), loadPositions(), loadHireDates()
- saveEmployees(), saveDepartments(), savePositions(), saveHireDates()


8. ПОИСК И СОРТИРОВКА
================================================================================

8.1. Поиск сотрудников
------------------------------------------------
Метод: DataManager::findEmployees(const EmployeeSearchFilter& filter)

Фильтры:
- По отделу (useDepartmentId)
- По должности (usePositionId) - только для Worker
- По зарплате (useMinSalary, useMaxSalary)
- По имени (useNameFragment) - поиск подстроки

8.2. Сортировка сотрудников
------------------------------------------------
Метод: DataManager::sortEmployees(EmployeeSortKey key, bool descending)

Ключи сортировки:
- ById - по ID
- ByDepartment - по отделу
- BySalary - по зарплате
- ByLastName - по фамилии
- ByHireDate - по дате найма
